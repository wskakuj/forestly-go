🌲 ForestlyGO Release wydawanie wersji Android prosto z telefonu — jak release.py na komputerze

1 Paczka z plikami (zip)

Wskaż plik zip, który dostałeś (np. forestly-go-poprawki.zip). Rozpakuje się do głównego katalogu repo — dokładnie jak „Zamień pliki" na komputerze.

2 Wersja i notatka

3 Token GitHub (raz, przy pierwszym użyciu)

Token trzyma się tylko tego telefonu (pamięć przeglądarki) — nigdzie indziej nie wychodzi. Wersję na GitHubie sprawdzam nawet bez tokenu.
Jak stworzyć token (raz, 2 minuty)

GitHub → menu awatara (prawy górny róg) → Settings → na dole Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

Nazwa: forestlygo-release · Resource owner: wskakuj · Repository access: Only select repositories → zaznacz forestly-go.

Permissions → Repository permissions: Contents: Read and write, Workflows: Read and write. Na dole Generate token → skopiuj i wklej tutaj.

Jeśli token już masz — nie twórz nowego: kliknij go na liście, popraw Repository access (forestly-go) i uprawnienia (Contents + Workflows na Read and write), zapisz — i tu kliknij „Zapisz i sprawdź” jeszcze raz.
