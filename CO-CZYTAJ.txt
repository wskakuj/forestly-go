FORESTLY GO — poprawki po pierwszych dniach z natywną aplikacją
================================================================

CO NOWEGO / NAPRAWIONE
  1. IKONA — taka sama jak FORESTLY na PC. Poprzednio Android 8+
     pokazywał ikonę adaptacyjną Capacitora (słonia/logo), bo to
     osobna warstwa. Teraz foreground = pełna ikona z PC (drzewo,
     ramka, napis FORESTLY) na granatowym tle — na każdym launcherze.
  2. LOKALIZACJA — aplikacja może teraz prosić o uprawnienia
     do lokalizacji (dodane do manifestu). Przy pierwszym użyciu
     "Ustal z GPS" Android zapyta o zgodę.
  3. NUMER WYDZIELENIA — wpisujesz i tyle. Zielona strzałka
     zniknęła: numer dodaje się sam po Enterze albo gdy przejdziesz
     do kolejnego pola. Można wpisać kilka po przecinku: "10, 15/2".
  4. WYKAZ — widać teraz numer wydzielenia przy każdym opisie
     (tam, gdzie wcześniej była pusta kolumnka oddziału).
  5. NAZWA PLIKU EXCEL — po prostu NAZWA_WSI_DATA,
     np. "Laskow_2026-09-27.xlsx" (bez "Taksator_Nazwisko").
  6. MAPA — drogi i nazwy miejsc domyślnie włączone (przełącznik
     "drogi i nazwy" na pasku mapy), oraz WSZYSTKIE pinezki
     zapisanych opisów z podpisem numeru wydzielenia.
     Dotknięcie pinezki otwiera opis do edycji.
  7. EXCEL — usunięte puste kolumny oddz_poddz i pow_ha,
     kolumna nr_dzialek przemianowana na nr_wydzielenia.
  8. Podgląd OPTAX — usunięty dopisek "działki na końcu…".

INSTALACJA
  Rozpakuj do repo forestly-go ("Zamień pliki w folderze docelowym")
  i wydaj wersję jak zwykle (release.py albo ForestlyGO Release).
  Nowy APK zainstaluje się jako aktualizacja — ikona na ekranie
  głównym może potrzebować chwili albo restartu launchera, żeby
  się odświeżyć.

WAŻNE — NAPRAWA TOKENU PRZED WYDANIEM
  Jeśli przy wysyłaniu release wyskoczyło "Resource not accessible by
  personal access token" — token nie ma uprawnień do ZAPISU.
  GitHub → awatar → Settings → Developer settings → Fine-grained tokens
  → kliknij swój token:
    1. Repository access: Only select repositories → forestly-go
    2. Permissions → Contents: Read and write
    3. Permissions → Workflows: Read and write
  Zapisz zmiany. Potem w aplikacji ForestlyGO Release kliknij
  "Zapisz i sprawdź" ponownie — teraz sprawdza OD RAZU też próbę
  zapisu, więc taki problem wykryje zanim zaczniesz wysyłać.
  Ta paczka zawiera już poprawioną aplikację Release (release.html).

WAŻNE
  - Zmiana nazwy pliku Excel: stare pliki na Nextcloudie zostają
    pod starą nazwą; nowe wyślij się jako NAZWA_WSI_DATA.
  - Zmiana nazwy kolumny nr_dzialek → nr_wydzielenia: sprawdziłem
    kod FORESTLY na PC — nie czyta tych kolumn po nazwie, import
    idzie przez teksty opisów, więc nic się nie psuje.
