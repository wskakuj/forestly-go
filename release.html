🌲 Forestly Release wydawanie wersji prosto z telefonu — jak release.py na komputerze

1 Repozytorium i dostęp

Token trzyma się tylko tego telefonu (pamięć przeglądarki) — nigdzie indziej nie wychodzi. Jak go stworzyć — patrz niżej.
Jak stworzyć token (raz, 2 minuty)

GitHub → menu awatara (prawy górny róg) → Settings → na dole Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

Nazwa: forestly-release · Resource owner: wskakuj · Repository access: Only select repositories → zaznacz forestly-go (i FORESTLY, jeśli chcesz wydawać też kombajna).

Permissions → Repository permissions: Contents: Read and write, Workflows: Read and write. Na dole Generate token → skopiuj i wklej tutaj.

2 Paczka z plikami (zip)

Wskaż plik zip, który dostałeś (np. forestly-go-motyw.zip). Rozpakuje się do głównego katalogu repo — dokładnie jak „Zamień pliki" na komputerze.
